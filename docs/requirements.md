# Соответствие заданию Практикума

Источник: урок «Финальный проект спринта: приложение „Холодильник“»,
спринт 1, тема 7 курса `ap-backend-st`; изучен 21.10.2026 через
авторизованную сессию. Прочитаны ТЗ всех пяти функций, раскрытые подробные
описания, примеры и подсказки в тренажёре.

В тренажёре используется один файл `main.py`. В нём уже находилось
сохранённое решение с пятью функциями; отдельный стартовый репозиторий
или скачиваемый набор тестов на странице не указан.

| Требование | Реализация и проверка |
| --- | --- |
| Словарь продуктов, список независимых партий | `goods = {}`, `add`; `AddTests` |
| Ключи партии `amount`, `expiration_date` | `Decimal` и `date` либо `None`; `AddTests` |
| Новая партия не заменяет старые | Добавление в список; `test_batches_are_kept_separately` |
| Необязательная дата, `%Y-%m-%d`, `strptime` | `add`; тесты дат без ведущих нулей и високосного дня |
| Заметка: название с пробелами, количество, необязательная дата | `add_by_note`, разбор через `split`, добавление через `add`; `NoteTests` |
| Поиск подстроки без учёта регистра | `find`, `lower`; `SearchTests` |
| Сумма всех партий всех совпадений через `find` | `get_amount`, аккумулятор `Decimal('0')`; `SearchTests` |
| Текущая дата и горизонт дней, по умолчанию 0 | `get_expired`; `ExpirationTests` |
| Срок годности включительно до даты горизонта | Сравнение `<=`; тесты сегодняшней даты и границы года |
| Партии без даты исключены | Явная проверка `is not None`; `test_no_expiration_is_never_included` |
| Результат сроков: список кортежей с положительной суммой | `get_expired`; примеры курса и тест нулевого количества |
| Без интерактивного `input()` | Вызовы с явными аргументами, отдельный `demo.py` |

В основном ТЗ `get_expired` явно указано накопить сумму всех подходящих
партий, а затем добавить один кортеж на продукт. Это согласуется с
подробными примерами: яйца двух партий дают один результат с суммой 5.

Архитектура оставлена модульной и соответствует уровню раздела «Основы
Python»: стандартная библиотека, без Django, API, базы данных и сторонних
пакетов. `demo.py`, документация и локальные тесты отделены от файла решения.

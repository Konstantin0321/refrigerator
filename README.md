# Refrigerator

Учебный проект «Холодильник» из первого спринта курса Яндекс Практикума
«Ассоциированные программы: Бэкенд-разработка», тема «Основы Python».
Модуль хранит продукты отдельными партиями, учитывает их количество
и срок годности, позволяет искать продукты и получать сводные данные.

## Технологии

Python 3, стандартные модули `datetime`, `decimal` и `unittest`.
Локальная проверка выполнена на Python 3.12.14. Внешних зависимостей нет.

## Установка

Установите Python 3.12 и Git. Для приватного репозитория нужен доступ
к GitHub-аккаунту владельца.

```sh
git clone https://github.com/Konstantin0321/refrigerator.git
cd refrigerator
```

Установка пакетов через pip не требуется. В Windows вместо `python`
можно использовать `py`, если интерпретатор доступен через эту команду.

## Запуск

```sh
python demo.py
```

Демонстрация добавит яйца и воду, выведет найденные продукты, общее
количество яиц (14) и партии с истёкшим или истекающим сегодня сроком.
Она использует локальный словарь, не изменяя `main.goods`.

Решение задания находится целиком в `main.py`. Оно не запрашивает
интерактивный ввод и не печатает ничего при импорте или запуске
`python main.py`: по условиям курса функции вызываются с явными аргументами.

```python
from decimal import Decimal
from main import add, add_by_note, find, get_amount, get_expired

goods = {}
add(goods, 'Яйца', Decimal('10'), '2026-10-22')
add_by_note(goods, 'Яйца гусиные 4')
add_by_note(goods, 'Вода питьевая 1.5')

print(find(goods, 'яйц'))          # ['Яйца', 'Яйца гусиные']
print(get_amount(goods, 'ЯЙЦ'))    # Decimal('14')
print(get_expired(goods, 2))      # Результат зависит от текущей даты.
```

## Контракты функций

| Функция | Поведение |
| --- | --- |
| `add(items, title, amount, expiration_date=None)` | Добавляет отдельную партию; возвращает `None`. |
| `add_by_note(items, note)` | Разбирает одну заметку `название количество [дата]`, вызывает `add`; возвращает `None`. |
| `find(items, needle)` | Возвращает список названий с подстрокой без учёта регистра. |
| `get_amount(items, needle)` | Через `find` суммирует все партии подходящих продуктов; возвращает `Decimal`, включая `Decimal('0')`, если совпадений нет. |
| `get_expired(items, in_advance_days=0)` | Возвращает список `(название, Decimal)` с суммой подходящих партий для каждого продукта. |

Словарь имеет форму `название: [{'amount': Decimal, 'expiration_date': date | None}]`.
Название может содержать пробелы. Дробная часть количества отделяется точкой.
Для точных вычислений передавайте количество строкой или `Decimal`.
Даты принимаются строками по формату `DATE_FORMAT = '%Y-%m-%d'`, в том числе
без ведущих нулей (`2023-9-30`), и сохраняются как `datetime.date`.

`get_expired` учитывает даты **включительно** до
`date.today() + timedelta(days=in_advance_days)`. Партии без даты исключаются;
в результат попадают только продукты с положительной суммой подходящих партий.
Поисковые функции не изменяют словарь и сохраняют порядок названий.

Некорректная дата вызывает `ValueError`, некорректное количество —
`decimal.InvalidOperation`. Заметка без названия или количества вызывает
`ValueError`. Ошибки не скрываются, неуспешное добавление не меняет словарь.
Ограничения на положительность количества, не предусмотренные заданием,
дополнительно не вводятся.

## Тестирование

Из корня проекта:

```sh
python -m unittest discover -s tests -v
```

28 тестов проверяют примеры Практикума, несколько партий, дробные количества,
поиск без учёта регистра, отсутствие совпадений, необязательные даты,
ошибки ввода, високосную дату, далёкое будущее, границы горизонта годности,
исключение партий без даты и отсутствие изменений данных при чтении.
Для проверок срока годности текущая дата фиксируется через `unittest.mock`.

21.10.2026 локально успешно выполнены все 28 тестов и `python demo.py`.
Этот же `main.py` проверен кнопкой «Проверить» в тренажёре Практикума:
получено сообщение «Это победа!». Количество скрытых тестов платформа
не отображает.
